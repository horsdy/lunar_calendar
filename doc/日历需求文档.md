# 日历 APP 需求文档

|------|------|

---

## 2. 项目概述

开发一款面向 Android 平台的日历应用，支持公历与**中国农历**双历展示，并提供桌面小组件，便于用户快速查看当前日期与农历信息。

---

## 3. 功能需求

### 3.1 日历主应用

| 需求编号  | 需求描述                                                             | 优先级 |
|-------|------------------------------------------------------------------|-----|
| F-001 | **显示中国农历**：应用内日历需同时展示公历日期与对应的中国农历日期（农历月、日）。                      | 高   |
| F-002 | 支持按公历月/年切换视图，切换时农历信息同步正确显示。                                      | 高   |
| F-003 | 当日日期需有明确标识（如高亮或标记,高亮形状为长方形,今天与选中的高亮颜色有区分）,切换到另一个月时取消全部item的选中状态。 | 中   |
| F-004 | 农历信息展示需符合常见习惯（如正月初一、腊月廿三等）。                                      | 高   |
| F-005 | 一周的开始默认从周一开始,同时增加设置入口(用齿轮icon),设置窗口是一个单独的Activity           | 中   |
| F-006 | 点击哪一天,就在下面显示当天的公历年月日与农历月日,并显示距离今天的+/-天数                    | 高   |
| F-007 | 日历的显示字体稍大                                                                       | 中   |
| F-008 | 不要做上个月和下个月的按钮,做左右滑动,左滑:上个月,右滑动:下个月,要有滑动效果                 | 高   |
| F-009 | 顶部右边放置一个按钮(文本显示:今),点击返回到今天的日视图,选中今天                           | 高   |
| F-010 | 桌面icon 使用常见日历icon, 类似安卓系统自带的日历icon                                     | 高   |

### 3.2 日历设置
| 需求编号  | 需求描述 | 优先级 |
|-------|----------|--------|
| S-001 | 包含子菜单:一周的开始日,版本,作者,联系方式 | 高 |
| S-001 | 子菜单一周的开始日,下拉框有2个选项:周一,周日,默认是周一 | 高 |

### 3.2 日历小组件

| 需求编号 | 需求描述 | 优先级 |
|----------|----------|--------|
| W-001 | 提供**日历小组件**，可添加到系统桌面。 | 高 |
| W-002 | **小组件显示内容**：<br>• **第一行**：公历 **月/日 星期**（如：2月9日 周一）；<br>• **第二行**：**农历 月/日**（如：正月十二）。 | 高 |
| W-003 | 小组件展示的日期与主应用一致，且随系统日期变化/设置日期 自动更新。 | 高 |
| W-004 | 小组件尺寸需适配常见规格（如 2×2、2x1、4×2），至少支持一种可完整显示上述两行内容的尺寸。 | 中 |
| W-005 | 字体颜色为白色, 背景色为 #539de6 ,透明度:0% | 高 |
| W-006 | 可以点击,点击打开主应用 | 高 |

## 4. 非功能需求

### 4.1 运行环境与兼容性

| 需求编号 | 需求描述                                                                          | 优先级 |
|----------|-------------------------------------------------------------------------------|--------|
| NF-001 | **目标运行操作系统**：**Android 15**。                                                  | 高 |
| NF-002 | **兼容性**：需**同时兼容 Android 14**，即在 Android 14 与 Android 15 上均可正常安装、运行并正确显示公历与农历。 | 高 |
| NF-003 | 在兼容系统版本范围内，需适配不同屏幕尺寸与分辨率。                                                     | 中 |

### 4.2 性能与体验

| 需求编号 | 需求描述 | 优先级 |
|----------|----------|--------|
| NF-004 | 日历与农历计算准确，无跨月、跨年错误。 | 高 |
| NF-005 | 小组件刷新及时，日期变更后无需用户手动操作即可更新。 | 高 |

## 5. 小组件显示示例

```
┌─────────────────┐
│   2月9日 周一     │   ← 第一行：公历 月/日 星期
│    正月十二       │   ← 第二行：农历 月/日
└─────────────────┘
```
尺寸: 2x2
---

## 6. 约束与假设

- 农历算法需覆盖 1900–2100 年或产品约定区间的准确转换。
- 小组件实现方式遵循 Android 标准（如 App Widget / 微件 API），以兼顾 Android 14/15 行为。
- 无特殊说明时，默认使用系统当前日期与用户所在时区。

---

## 7. 验收标准概要

1. **主应用**：在 Android 14/15 设备上可安装运行，日历界面正确显示公历及对应中国农历。
2. **小组件**：可在桌面添加小组件，第一行显示公历月/日，第二行显示农历月/日，且随日期自动更新。
3. **兼容性**：在 Android 14 与 Android 15 上上述功能均通过验证。
